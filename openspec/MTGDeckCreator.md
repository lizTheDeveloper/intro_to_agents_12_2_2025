# MTG Deck Creator and Testing System

## Functionalities
- The system should be able to consume the MTG JSON API to get up-to-date information about the cards.
- The system should be able to construct decks according to user's requirements or predefined configurations. 
- The system will employ strategies that enhance deck coherence and competition level.
- The system should be able to conduct an automated testing of the generated deck by using an evolutionary testing algorithm.

## Program Interfaces
- The system will interact with the MTG JSON API to fetch the necessary data.
- The system may provide a user-friendly interface for defining strategies and configurations.

## System Attributes
- **Reliability**: The system should consistently generate competitively balanced decks and the testing algorithm should be able to thoroughly test the decks.
- **Efficiency**: The system should effectively utilize the available resources while generating decks and conducting tests.
- **Security**: If there will be user inputs or any external interactions, the system should prevent any security breaches/attacks.
