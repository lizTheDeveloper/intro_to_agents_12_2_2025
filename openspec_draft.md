# Project Name: MTG Deck Builder

## System Objectives:

Create a software system capable of producing playable, competitive, and enjoyable MTG decks using the MTG JSON API. The system should also include an evolutionary algorithm for testing the decks.

## Component Interactions:

The system would include modules for interacting with the MTG API, forming decks, applying strategies, testing the decks, and presenting the data to the users.

Details about how data from the MTG JSON API will be structured within the system. Additional details about how the data will be stored, accessed, and manipulated would be added here.
