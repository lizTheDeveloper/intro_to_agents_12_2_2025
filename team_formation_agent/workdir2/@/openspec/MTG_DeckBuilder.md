# MTG Deck Builder OpenSpec

## Objectives

Create a software system that

1. Can produce Magic: The Gathering (MTG) decks that are playable, competitive, and fun.
2. Select strategies that work together.
3. Implement an evolutionary testing algorithm to test the decks.

## Building Blocks

1. MTGJSON API: To pull card data and use it for deck building.
2. Software System: Responsible for MTG deck creation.
3. Strategy Selection: Used for selecting strategies that work together.
4. Evolutionary Testing Algorithm: Designed to test the decks.

## Constraints & Requirements

Decks must be fun, playable, and competitive. The strategies selected must work together.
